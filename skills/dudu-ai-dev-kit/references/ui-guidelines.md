# UI 设计规范

## 整体风格
- **风格不固定**：根据每个软件的定位和受众来定
- **但必须风格统一**：所有窗口、弹窗、按钮风格必须一致
- **单一强调色**：整个软件只用一个强调色，不要五颜六色

## 字体
- **非衬线体**：固定用 "Microsoft YaHei UI"
- 字号根据控件层级调整，不要随意用

## 间距与圆角
- 按钮 padding：5px 14px
- 控件圆角：4px
- 工具栏间距：4px ~ 8px
- 面板间距：根据层级递减
- **滚动条用极窄圆角**：宽度 6px 左右，细一点
- **界面尽量紧凑**：能不出现滚动条就不要出现（前提是不能遮挡内容）

## 动效要求
- **所有点击交互都要有动效**：按钮 hover、按下、选中状态都要有视觉反馈
- 不要做"点了没反应"的死按钮

## 模态窗口
- ⚠️ **绝对不要把模态窗口的背景设成透明**
- 模态对话框必须有不透明的背景
- 透明底只适合工具提示、浮层之类的非模态元素

## 文字排版
- **文字排版要整齐**：对齐、间距、行距都要统一
- 不要有的地方左对齐有的右对齐，不要行距忽大忽小

## 控件紧凑度与对齐（重要坑点）
- **控件空白区域不能太大**：QLabel、QPushButton 等控件自带的内边距/外边距要尽量压小
- 很多控件默认有一块**透明的空白区域**，肉眼看不到，但实际占着位置：
  - 看起来文字左对齐了，实际文字前面还有一块透明 padding
  - 两个控件"对齐"了，实际差了几像素
- **解决办法**：
  - 显式设置 `setContentsMargins(0, 0, 0, 0)` 去掉默认内边距
  - 显式设置 `setSpacing(0)` 去掉布局默认间距
  - 对齐的时候不要靠"感觉"，要靠数值
  - 调试对齐问题时，给控件加个临时背景色，就能看到那块透明区域

## Windows 标题栏
- 所有顶层窗口**强制深色标题栏**（用 DWM API）
- 不要用系统默认的浅色标题栏

## 图标
- **优先用现成图标库**（如 IconPark），风格统一
- 没有合适的再 AI 生成
- 图标风格要多样，不要全是一个风格
